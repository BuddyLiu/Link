# LINK ACTION 操作标记（离线/文本模式）

> **用途**：元模型在 LINK 的**离线/文本响应模式**下，通过在回复末尾追加 `[[ACTION:xxx]]` 标记来触发系统操作。
> **触发机制**：LINK 的系统提示词描述可用的 ACTION 标记，元模型生成回复时把标记放在**回答末尾**，LINK 解析并执行。
> **适用场景**：不需要 Function Calling 的简单操作，或作为工具调用的补充。
> **与 link-tools.md 的关系**：在线模式优先用 Function Calling；此文档适用于文本标记路径（`_process_action_marker` 解析）。

---

## 标记格式

```
[[ACTION:操作名|参数1=值1|参数2=值2]]
```

- **位置**：放在回答**末尾**（不要放在中间或开头）。
- **分隔**：参数之间用 `|` 分隔；`key=value` 形式。
- **容错**：也支持 `ACTION: 操作名 参数1=值1 参数2=值2` 自然语言形式（大小写不敏感）。
- **无操作时**：如果不需要执行操作，**不要加任何标记**。

---

## 操作清单

### 一、任务管理

| 操作 | 触发条件 | 参数 | 说明 |
|------|---------|------|------|
| `CREATE_TASK` | 用户要求规划/安排/组织某事 | 无（用原始输入） | 创建复杂任务（旅行/聚会/项目/学习计划） |
| `LIST_TASKS` | 用户要查看任务列表 | 无 | 列出所有任务 |

### 二、学习与规划引擎

| 操作 | 触发条件 | 参数 | 说明 |
|------|---------|------|------|
| `LEARN` | 用户要求学习某个主题 | 无（用原始输入） | LLM 学习主题并存入记忆 |
| `PLANNING_INFO` | 用户问规划引擎信息 | 无 | 返回规划引擎状态/模板 |

### 三、文件操作

| 操作 | 参数 | 说明 |
|------|------|------|
| `FILE_READ` | `path=文件路径` | 读取文件 |
| `FILE_WRITE` | `path=文件路径\|content=完整内容` | 写入文件 |
| `FILE_EDIT` | `path=路径\|old=原内容\|new=新内容` | 字符串替换编辑 |
| `FILE_GREP` | `pattern=关键词\|include=.py` | 搜索文件内容 |
| `FILE_GLOB` | `pattern=**/*.py` | 按文件名模式搜索 |
| `FILE_DELETE` | `path=文件路径` | 删除文件 |
| `FILE_AUTHORIZE` | `path=路径\|mode=read\|type=temporary` | 授权外部路径访问 |
| `FILE_AUTH_LIST` | 无 | 查看已授权路径 |

**路径语义**：
- 相对路径默认落到工作目录 `~/LINK-Workspace`
- 读源码目录用绝对路径；写源码目录需先 `FILE_AUTHORIZE`
- 授权目录后，其下所有文件自动获得读写权限（继承机制）

**写入规范**：把完整内容放在 `content=` 中，回复只需写操作标记和简短确认。

### 四、项目知识库

| 操作 | 触发条件 | 说明 |
|------|---------|------|
| `SCAN_PROJECT` | 用户要求了解/扫描当前项目 | 扫描项目生成上下文 |
| `PROJECT_INFO` | 用户问项目的技术栈/结构 | 返回项目上下文 |

### 五、网络搜索

| 操作 | 参数 | 说明 |
|------|------|------|
| `SEARCH_WEB` | `query=搜索关键词` | 搜索互联网 |

**注意**：用户问天气、新闻、实时信息或你不知道的内容时，**必须用 `SEARCH_WEB` 搜索**，不要说自己不知道。

### 六、系统命令

| 操作 | 参数 | 说明 |
|------|------|------|
| `EXEC_CMD` | `command=命令\|timeout=30` | 执行安全系统命令 |

**限制**：仅安全命令（`ls`/`cat`/`pwd`/`git status` 等），禁止危险命令。

---

## 使用示例

1. **创建任务**：
   ```
   📋 好的，我来为你规划这个项目。
   [[ACTION:CREATE_TASK]]
   ```

2. **写入文件**：
   ```
   ✅ 已为你创建文件。
   [[ACTION:FILE_WRITE|path=notes.md|content=今日学习要点：...]]
   ```

3. **搜索网络**：
   ```
   🔍 让我搜索一下相关信息。
   [[ACTION:SEARCH_WEB|query=金星引力辅助计算]]
   ```

4. **读取文件**：
   ```
   📖 正在读取配置文件。
   [[ACTION:FILE_READ|path=/Users/liubo/Codes/LINK/config/settings.json]]
   ```

5. **执行命令**：
   ```
   💻 查看当前目录。
   [[ACTION:EXEC_CMD|command=pwd|timeout=10]]
   ```

---

## 行为规范

1. **标记在末尾**：操作标记永远放在回复的最后一行，不要在正文中穿插。
2. **一次一个主操作**：通常一个回复触发一个主操作；复杂场景可追加多个。
3. **不要标记无需执行**：纯文本回答（问候、闲聊、简单知识）不加标记。
4. **参数转义**：`content=` 中的内容若含 `|` 或 `=` 需注意解析；长内容建议用 `FILE_WRITE` 而非标记内嵌。
5. **失败回退**：如果 ACTION 执行失败，LINK 会返回错误信息，此时可改用 Function Calling 或直接文本回复。
