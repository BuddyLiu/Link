# LINK 记忆去重优化日志

**日期**：2026-08-12
**目标**：解决记忆重复存储问题（验证时发现"姓名：陈晨"出现 4-6 次）

---

## 一、问题根源

用户信息类事实有三个保存来源，格式不同且互不查重：

| 来源 | 格式示例 |
|------|---------|
| 正则提取（`_regex_extract_facts`） | `用户叫陈晨` |
| LLM 提取（`_extract_facts_from_conversation`） | `姓名：陈晨` |
| 工具调用（`save_user_fact`） | `用户姓名: 陈晨` |

三者都调用 `add_fact_memory`，但该方法不检查历史记忆 → 同一信息（姓名/职业/邮箱等）重复存储多条。

## 二、修复

**`MemoryManager.add_fact_memory` 加去重**：
1. 归一化类别：`_extract_fact_category` 提取 姓名/职业/偏好/联系方式 等类别键
2. 查历史：`_find_duplicate_fact` 扫描 fact 记忆，同类别且内容相似（`_fact_similar` 提取核心值比较）
3. 命中则 `update_memory` 替代旧记录（保留原 id），否则正常新增
4. 仅对用户信息类事实去重（`_is_user_fact`），项目知识等非用户事实保持原行为

## 三、清理存量

用去重逻辑扫描记忆库：**删除 356 条重复，499 → 139 条**（瘦身 71%）。
- 姓名/邮箱/职业等关键类别各保留 1 条
- 手动清理残留（`用户叫陈晨，是一名` 等后缀变体）
