# LINK 手动执行模式说明

## 背景
根据用户需求分析和测试反馈，LINK系统已从**自动执行模式**调整为**手动执行模式**。用户现在可以完全控制任务执行的节奏和步骤，确保每次操作都需要明确指令。

## 修改内容

### 主要更改
1. **移除了任务创建后的自动执行功能**
   - 原代码：任务创建后自动执行前2个步骤
   - 新代码：任务创建后等待用户手动开始执行

2. **改进了任务管理逻辑**
   - 任务状态从 `executing` 改为 `pending`
   - 添加明确的手动执行提示信息
   - 优化了任务ID提取和验证机制

3. **保留了灵活的执行选项**
   - 手动单步执行：`开始执行 <任务ID>`
   - 继续下一步：`完成步骤 <任务ID>`
   - 自动多步执行：`开始执行 <任务ID> 自动`

### 技术实现
修改了 `link/main.py` 中的 `_handle_complex_task_request()` 方法：
```python
# 原代码 - 自动执行
execution_response = self._auto_execute_task_steps(task.id, steps_to_execute=2)
response = self._format_task_plan_response(...)
response += f"\n\n🚀 自动开始执行任务...\n{execution_response}"

# 新代码 - 手动执行
response = self._format_task_plan_response(...)
response += f"\n💡 任务已创建，等待手动执行。\n"
response += f"   输入'开始执行 {task.id}'开始执行第一步\n"
response += f"   或输入'查看任务 {task.id}'查看详细规划"
```

## 使用流程

### 1. 创建任务
```
输入: 帮我规划一个周末旅行
输出: ✅ 任务创建成功！
     📋 任务: 帮我规划一个周末旅行
     💡 任务已创建，等待手动执行。
       输入'开始执行 project_20260303_140000'开始执行第一步
       或输入'查看任务 project_20260303_140000'查看详细规划
```

### 2. 手动开始执行
```
输入: 开始执行 project_20260303_140000
输出: ✅ 步骤1执行完成：项目目标分析
     💡 继续下一步请输入：'完成步骤 project_20260303_140000'
```

### 3. 逐步执行后续步骤
```
输入: 完成步骤 project_20260303_140000
输出: ✅ 步骤2执行完成：任务分解
     💡 继续下一步请输入：'完成步骤 project_20260303_140000'

输入: 完成步骤 project_20260303_140000
输出: ✅ 步骤3执行完成：资源分配
     🎉 所有步骤已完成！任务'帮我规划一个周末旅行'执行完成。
```

### 4. 查看任务状态
```
输入: 任务列表
输出: 📋 活跃任务 (1 个):
     1. 帮我规划一个周末旅行
        ID: project_20260303_140000
        状态: executing
        进度: 3/3 (100%)
        创建时间: 2026-03-03 14:00
```

### ✅ 完全控制
- 用户决定何时开始执行任务

- 随时可以暂停、继续或查看进度

### ✅ 透明可见
- 清晰的执行状态显示
- 详细的步骤执行结果

### ✅ 灵活适应
- 适合需要深思熟虑的复杂任务
- 允许用户在每个步骤后调整策略
- 支持批量执行和单步执行两种模式

## 配置选项

如果需要重新启用自动执行，可修改配置：
```python
# config/settings.py 中添加
planning:
  auto_execute_on_create: false  # 设为true可恢复自动执行
  auto_execute_steps: 2          # 自动执行的步骤数
```
