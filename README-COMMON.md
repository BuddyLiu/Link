**JARVIS智能助手系统**

这是一个像电影《钢铁侠》里贾维斯那样的AI助手系统。目前已经完成第三阶段的开发。

**当前状态**
- 已完成：复杂任务规划、自我反思、主动提醒功能
- 版本：3.0
- 目标：做一个能记住你、主动帮你做事、控制各种设备的智能管家

**如何启动**
- 直接运行：`python main/run_jarvis.py`（默认模式，会主动监控）
- 命令行模式：`python main/run_jarvis.py cli`（你问它答，不主动监控）
- 网页服务：`python main/run_jarvis.py web`
- 测试：`python main/run_jarvis.py test`
- 演示：`python main/run_jarvis.py demo`
- 简单网页界面：`python main/run_jarvis.py simple-web`

**系统结构**
主要分这几块：
- 启动入口（用来运行程序）
- 核心引擎（负责思考和规划）
- 工具系统（调用各种功能）
- 记忆模块（存储信息）
- 反思模块（自我检查）
- 提醒模块（主动提醒你）

**已实现功能**
- 第一阶段：能调用基础工具（查时间、操作文件等），有命令行界面
- 第二阶段：加入了记忆功能（能存储和回忆信息）
- 第三阶段：能规划复杂任务、自我反思、主动提醒
